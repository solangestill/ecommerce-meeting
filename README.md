## 开会方式

- 页面给出具体会前材料、汇报问题和录音依据时间。
- 在事项所在行直接点“未完成、进行中、已完成、需协助”，或用下拉框选择其他状态。
- 不弹出编辑窗口，不跳转页面，不强制填写完成依据。需要时可在本页展开选填资料。
- 现场口头讲清负责人、动作、期限和支持需求，详细纪要在提供录音后整理。

## 记录与兼容
