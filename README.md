# 电商部会议工作台

会议展示与本地进度管理网页。已确定的店铺整合方向：**玄甲店铺作为主店，美安士店铺转移至玄甲店铺**。

## 功能

- 会议总览、待办状态与完成依据
- 重点客户案例、整合清单、渠道工具复盘
- Accio Work业务演示提纲、会议结论与下一步
- 新增和编辑待办、客户与渠道，搜索筛选、期限提示
- 浏览器本地保存，JSON导出导入，Markdown会议纪要导出
- 方向键切换、全屏、讲解提示、移动端与打印布局

## 数据说明

初始状态只有“整合方向确定”为已完成，其余事项均为待更新。页面不会假设业务已经完成。

业务记录保存在当前浏览器的localStorage中，不上传GitHub或其他服务器，不自动跨设备或多人同步。换设备前导出JSON，再在新设备导入；导入会替换该浏览器现有记录。清除站点数据或更换浏览器可能使本地记录不可用，请保留导出备份。

客户、渠道、责任人和业务金额初始均未填写。当前仓库仅发布界面和通用任务模板。
